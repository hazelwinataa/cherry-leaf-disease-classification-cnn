# Dataset access and provenance

The 3,642 original JPEG images used in the academic exercise were **not** supplied for this repository. The original notebook expects the relative folder `data/cherry/` to contain one subdirectory per class with `.jpg` files. Do not redistribute any third-party source image collection without appropriate permission. The `.gitignore` intentionally excludes the image dataset. Saved metric tables and figures can be inspected from the original executed notebook without downloading the data.

**Important:** the executed notebook used a shared validation/test subset and does not document a genuinely independent 70:15:15 evaluation. Reproduction and publication should correct that before claiming held-out performance.
